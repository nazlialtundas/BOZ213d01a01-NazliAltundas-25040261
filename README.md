# Kıyafet için Renk Uyumu | Clothing Color Matching

## TR 

Kullanıcının seçtiği kıyafet rengine göre, o renkle uyumlu olabilecek diğer renkleri öneren basit bir Python programıdır.

Program, kullanıcının seçtiği ana renge göre kıyafet üzerinde kullanılabilecek tamamlayıcı renkleri önerir.

-Özellikler
- Kullanıcıya farklı renk seçenekleri sunar.
- Seçilen renge uygun renkleri önerir.
- Program while döngüsü sayesinde tekrar tekrar kullanılabilir.
- 0 seçeneği ile programdan çıkılabilir.

-Nasıl Kullanılır?
1. Python'un bilgisayarınızda kurulu olduğundan emin olun.
2. Program dosyasını çalıştırın.
3. Ekranda gösterilen renklerden birini seçin.
4. Seçtiğiniz renge göre önerilen uyumlu renkleri görüntüleyin.
5. Yeni bir renk seçmek için programı kullanmaya devam edin.
6. Programdan çıkmak için 0 seçeneğini girin.


## EN

A simple Python program that suggests colors that may go well with the clothing color selected by the user.

The program recommends complementary colors that can be used in an outfit based on the main color selected by the user.

Features

- Offers the user different color options.
- Suggests colors that match the selected color.
- Can be used repeatedly thanks to a "while" loop.
- The program can be exited by selecting option "0".

How to Use

1. Make sure Python is installed on your computer.
2. Run the program file.
3. Choose one of the colors displayed on the screen.
4. View the recommended matching colors for your selected color.
5. Continue using the program to choose another color.
6. Enter "0" to exit the program.
